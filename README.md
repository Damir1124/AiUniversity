# 🎓 AiUniversity — Система управления учебными знаниями

Vault, синхронизированный между **DeepSeek Harness (dsh)** и **Obsidian**. Нейросеть берёт «сырое» и раскладывает по полочкам в идеальную для запоминания базу знаний.

## 🧠 Идея

1. **Сбор** — весь исходный материал (лекции, методички, пособия) складывается в `raw/`.
2. **Фильтрация «без воды»** — dsh выступает жестким редактором: выжимает факты, формулы, термины, алгоритмы. Вырезает вводные, лирику, историю.
3. **Режимы** — одна тема перерабатывается под разные цели через профили.
4. **Obsidian-совместимость** — Markdown + YAML (frontmatter) + внутренние связи `[[термин]]` → автоматически строится граф знаний.

## 🗂️ Структура Vault

| Папка | Назначение | Обозначение |
|---|---|---|
| `raw` | Исходники (изолированы, НЕ в графе) | 📥 вход |
| `00_Inbox` | Неразобранное | 🗄 |
| `01_Сырьё` | Копии исходников под обработку | 📄 |
| `02_Знания` | Сухие выжимки + объяснения | 🧠 |
| `03_Экзамены` | Вопрос–ответ, шпаргалки | 🎓 |
| `04_Термины` | Сквозные термины `[[термин]]` | 🏷 |
| `05_Шпаргалки` | Компактные выжимки | 📄 |
| `06_Отчеты` | Логи обработки | 🗒 |
| `_scripts` | Фильтры и шаблоны | ⚙️ |
| `_config` | Конфигурация системы | ⚙️ |

**Начать навигацию:** откройте [[Карта знаний]].

---

## 🔄 Режимы обработки

| Режим | Команда | Назначение | Куда идет |
|---|---|---|---|
| **Сухая выжимка** | `dry` | факты, формулы, цепочки | `02_Знания` |
| **Экзамен** | `exam` | Вопрос → точный ответ + шпаргалка | `03_Экзамены` |
| **На пальцах** | `plain` | упрощение без потери точности | `02_Знания` |
| **Связывание** | `links` | извлечение терминов → сквозные `[[термин]]` | `04_Термины` |

---

## ⚙️ Конфигурация

Всё описано в `_config/dsh_process.yaml` и `_config/properties.schema.yaml`:

- режимы и их `target_dir` (полочки);
- фильтры `keep`/`drop` для сухой выжимки;
- пути и расширения для обработки;
- настройки Git/GitHub-синхронизации.

---

## 🚀 Быстрый старт

1. Положите исходники в `raw/` (или `01_Сырьё/`).
2. Запустите скрипт нужного режима (см. `_scripts/README.md`).
3. Откройте папку как Vault в Obsidian.
4. Смотрите граф через любую заметку или [[Карта знаний]].
