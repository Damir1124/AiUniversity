# =====================================================================
# _scripts/prompts/README.md — Нейросетевые промпт-фильтры (dsh)
# =====================================================================
# Это САМИЕ «фильтры без воды». Каждый .prompt.md — строгий профиль,
# который dsh применяет к исходному материалу, чтобы получить готовую
# Markdown-заметку для Obsidian.

# ---------------------------------------------------------------------
# Как это работает
# ---------------------------------------------------------------------
# 1. Внутри каждого промпта есть плейсхолдер {source}.
# 2. При вызове dsh исходный текст подставляется вместо {source}.
# 3. Нейросеть возвращает готовую заметку по шаблону (frontmatter + разделы).
# 4. Результат сохраняется в нужную полочку (02_Знания / 03_Экзамены / 04_Термины).

# ---------------------------------------------------------------------
# Файлы
# ---------------------------------------------------------------------
#   dry.prompt.md   -> Сухая выжимка (02_Знания)
#   exam.prompt.md  -> Экзаменационный режим (03_Экзамены)
#   plain.prompt.md -> Объяснение на пальцах (02_Знания)
#   links.prompt.md -> Семантическое связывание (04_Термины)

# ---------------------------------------------------------------------
# Как вызывать (в dsh-команде)
# ---------------------------------------------------------------------
# Пример обработки одним файлом:
#   Обработай файл raw/лекции/математика/Лекция5.md в режиме dry.
#   Примени профиль _scripts/prompts/dry.prompt.md, подставив содержимое
#   файла вместо {source}. Результат сохрани в 02_Знания/Математика/.
#
# Либо передайте профиль как item/rule в dsh-обработке для папки.

# ---------------------------------------------------------------------
# Совет
# ---------------------------------------------------------------------
# Не редактируйте системные правила ниже «Исходный материал» вручную
# при каждом вызове — они задают поведение. Меняйте только подчеркнутые
# прямые правила, если нужно изменить жёсткость фильтрации.
