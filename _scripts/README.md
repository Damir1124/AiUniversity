# Обзор
# -----
# Скрипты в _scripts/. Запускаются из командной строки (PowerShell).
# Для нейросетевой обработки dsh подаёт источники сюда в виде PROMPT-режима.
#
# Быстрая схема:
#   raw/ (исходники)  ->  process.ps1 <mode>  ->  полочка (02_Знания|03_Экзамены|04_Термины)
#
# Modes:  dry  |  exam  |  plain  |  links

# =====================================================================
# 1. Каталог скриптов
# =====================================================================
#   process.ps1        - главная точка входа, выбирает режим
#   filters/dry.ps1    - сухая выжимка
#   filters/exam.ps1   - экзаменационный режим
#   filters/plain.ps1  - объяснение на пальцах
#   filters/links.ps1  - семантическое связывание
#   templates/*.md     - шаблоны выходных заметок
#   misc/sync.ps1      - синхронизация с GitHub
#   misc/init-git.ps1  - разовая инициализация репозитория

# =====================================================================
# 2. Обычный запуск (PowerShell)
# =====================================================================
#   cd C:\Users\...\AiUniversity
#   powershell -ExecutionPolicy Bypass -File _scripts\process.ps1 -Mode dry
#   powershell -ExecutionPolicy Bypass -File _scripts\process.ps1 -Mode exam
#   powershell -ExecutionPolicy Bypass -File _scripts\process.ps1 -Mode plain
#   powershell -ExecutionPolicy Bypass -File _scripts\process.ps1 -Mode links
#
# Параметры:
#   -Mode dry|exam|plain|links   Режим обработки (обязательно)
#   -InputDir raw|01_Сырьё       Источник (по умолч. raw)
#   -Force                        Перезаписать существующие заметки

# =====================================================================
# 3. Инициализация Git / GitHub (один раз)
# =====================================================================
#   powershell -ExecutionPolicy Bypass -File _scripts\misc\init-git.ps1
#
# Затем оставьте в _config/dsh_process.yaml remote на свой репозиторий.

# =====================================================================
# 4. Авторизация (если планируете пушить)
# =====================================================================
# Рекомендуется использовать PAT (Personal Access Token) или SSH-ключ.
# Детали в README. GitHub-синхронизация.

# =====================================================================
# 5. Куда класть исходники
# =====================================================================
# Положите .md-файлы исходников в raw/ (или укажите -InputDir).
# Скрипты читают их, присваивают SHA и генерируют заметки по шаблону.
# Примечание: для НЕЙРОСЕТЕВОЙ обработки (сама фильтрация текста)
# dsh использует эти же фильтры как пейл-профили — промпты в подпапке /prompts.
