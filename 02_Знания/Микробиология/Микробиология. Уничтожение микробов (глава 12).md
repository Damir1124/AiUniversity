# Микробиология. Уничтожение микробов в окружающей среде

## Определения (иерархия!)
- **Асептика** — комплекс мероприятий, предотвращающих попадание микробов **в рану/объект** (основа — стерилизация + дезинфекция).
- **Антисептика** — уничтожение микробов **в ране/на коже** (в живом организме).
- **Дезинфекция** — **частичное или полное** освобождение объектов от патогенных микробов (не всегда убивает споры).
- **Стерилизация** — **полное** обеспложивание объекта (освобождение от всех форм, включая споры).

## Антисептика (методы)
1. **Механическая** (удаление инфицированных тканей).
2. **Физическая** (повязки, дренаж).
3. **Химическая** (антисептики — галогены, окислители, спирты, кислоты, соли, фенолы).
4. **Биологическая** (антибиотики, бактериофаги).
- Основатели/идеи: Земмельвайс, Н.И. Пирогов.

## Методы дезинфекции
1. **Химический** (хлорсодержащие, перекись водорода 6%, формальдегид, лизол/крезол для фекалий и мокроты; муравьиная/уксусная кислота) — самый частый.
2. **Физический**: механические (вытряхивание, вентиляция), высокие температуры (кипячение +сода ≥15 мин, пастеризация, горячий воздух, пар), излучение.
3. **Биологический** (очистка стоков).
- Виды: текущая (в процессе работы), заключительная (после).
- **Пастеризация** — не стерилизация! (длит. 63–65°C, кратковр. 72–76°C, моментальная 85–90°C).
- Контроль: смывы, отсутствие возбудителя.

## Методы стерилизации
### Физические
**Тепловая**:
- **Фламбирование** (прожигание в пламени) — только стойкие к нагреву (металл, петля).
- **Сухожаровая (воздушная)** — в воздушных стерилизаторах (шкафах): 200°C/30 мин и др.; для стекла, металла; убивает и споры.
- **Автоклавирование** — горячий пар под давлением: режимы **132°C/2 атм/20 мин** и **120°C/1,1 атм/45 мин**; для стекла, крavфт-пакетов; текучий пар (100°C, вегетативные формы) — при открытом кране.
- **Тиндализация** — **дробная** стерилизация (ежедневное прогревание → прорастание спор → повтор; для сывороток, асцитической жидкости).
- Гласперленовый (шариковый) — стоматология.

**Лучевая (холодная)**: УФ, ВЧ, СВЧ, радиация, ИК — для термочувствительных; изделия в полиэтилене.
**Фильтрование** (стерилизующая фильтрация) — для препаратов, не выдерживающих нагрева (фильтры Зейтца, мембранные).

### Химические
- Газовый метод (пары формальдегида, окись этилена) — в газовых стерилизаторах; для оптики, полимеров; длительный цикл.

## Контроль стерилизации
- **Физико-химические тесты** (ампулы с кристаллами, цветные индикаторы).
- **Биологические индикаторы** (тест-культуры спор: B. stearothermophilus — для автоклавов, B. licheniformis — для воздушных).
- **Микробиологический контроль** (смывы, посевы из стерильных объектов; отсутствие роста).

## Суть главы
Иерархия: асептика (профилактика попадания) ← антисептика (в ране) ← дезинфекция (частичное) ← **стерилизация (полное, включая споры)**. Главный метод стерилизации — автоклавирование; дробная — тиндализация. Ключ запоминания: **стерилизация > дезинфекция > антисептика > асептика** (по "агрессивности").
