# Микробиология. Введение

## Определения

**Микробиология** (греч. micros — малый, bios — жизнь, logos — учение) — наука, изучающая систематику, морфологию, физиологию, генетику, экологию микробов, их взаимоотношения с другими формами жизни, патогенез инфекционных заболеваний; разрабатывает методы диагностики, лечения и профилактики инфекционных болезней.

**Микробы** — микроскопические живые существа (вирусы, бактерии, грибы, простейшие), видимые только с помощью увеличительных приборов.

## Мир микробов и основные группы

### Ключевые размеры (для запоминания)
| Объект | Размер | Метод |
|---|---|---|
| Клетка растения / диатомовые водоросли | ~100 мкм | световая |
| Клетка крови | ~10 мкм | световая |
| Бактерия | ~1 мкм | световая |
| Вирус человека/животных | до 200 нм (0,2 мкм) | электронная |
| Молекула | ~1 нм | электронная |

### Прокариоты vs эукариоты (главные отличия)
| Признак | Прокариоты | Эукариоты |
|---|---|---|
| Оформленное ядро | нет | есть |
| Ядерная мембрана, ядрышко | нет | есть |
| Рибосомы | 70S | 80S |
| Мембранные органеллы (митохондрии, ЭПС, Гольджи, лизосомы) | нет | есть |
| Митоз / мейоз | нет | есть |
| Клеточная стенка из пептидогликана | есть | нет |
| Тейхоевые кислоты | есть | нет |
| Устойчивость к облучению | высокая | низкая |
| Стерины в мембранах | нет (кроме некот. микоплазм) | есть |
| Дыхание | на мембранах / мезосомах | в митохондриях |
| Фагоцитоз / внутриклеточное пищеварение | нет | есть |

## Положение микробов в системе живых существ
- Э. Геккель (XIX в.) выделил микробов в отдельное царство **Protista (протисты)**.
- **Высшие протисты** — эукариоты (простейшие, микроскопические водоросли, микроскопические грибы).
- **Низшие протисты** — прокариоты (бактерии, сине-зелёные водоросли).
- К **миру микробов** относятся:
  1. **Надцарство эукариотов**: простейшие (подцарство животных), микроскопические водоросли (растения), микроскопические грибы.
  2. **Надцарство прокариотов** — царство бактерий, отделы:
     - **Gracilicutes** (грациликуты, тонкая клеточная стенка) — **грамотрицательные**;
     - **Firmicutes** (фирмикуты, толстая стенка) — **грамположительные**;
     - **Tenericutes** (тенерикуты, без стенки) — **микоплазмы**;
     - **Mendosicutes** (мендосикуты, дефектная стенка без пептидогликана) — **архебактерии** (термофилы, галофилы — экстремофилы).
  3. **Царство вирусов** (неклеточные формы).

## Предмет и задачи медицинской микробиологии
Главные задачи:
- изучение роли микробов в жизни человека и микрофлоры организма;
- изучение возбудителей инфекционных болезней (структура, метаболизм);
- влияние факторов среды на микробы и их сохраняемость;
- лабораторная диагностика и методы;
- разработка средств специфической профилактики и лечения (вакцины, сыворотки, иммуноглобулины, антибиотики);
- использование микробиологического синтеза.

## Виды (дисциплины) микробиологии
- **Медицинская**, **ветеринарная**, **сельскохозяйственная**, **промышленная (техническая)**, **пищевая**, **санитарная**, **фармацевтическая**, **космическая**, **геологическая**, **клиническая**, **экологическая**.
- **Разделы**: бактериология, иммунология, вирусология, микология, молекулярная биология/генная инженерия, микробная биотехнология.
- **Общая микробиология** — общие закономерности; **частная** — конкретные возбудители.

## Связи с другими науками
Физика, химия, биология, анатомия, гистология, биохимия, физиология, генетика; клинические и медико-профилактические дисциплины.

## Суть главы (кратко)
Микромир — это вирусы, бактерии, грибы и простейшие. Ключевой водораздел — прокариоты (нет ядра, 70S-рибосомы, пептидогликан) vs эукариоты. Микробиология систематизирует их, изучает их роль и разрабатывает методы диагностики/лечения/профилактики.
