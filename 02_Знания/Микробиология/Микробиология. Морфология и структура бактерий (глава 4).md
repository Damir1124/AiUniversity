# Микробиология. Морфология и структура бактерий

## Формы бактерий

### Шаровидные (кокки) — 0,5–1,0 мкм
| Вид | Расположение | Причины/деление |
|---|---|---|
| **Микрококки** | поодиночке | — |
| **Диплококки** | парами (2 клетки) | деление в 1 плоскости, клетки не расходятся (пневмококк, гонококк, менингококк) |
| **Стрептококки** | цепочкой | деление в 1 плоскости с сохранением связи (скарлатина, рожа, ангина) |
| **Тетракокки** | по 4 (в 2 плоскости) | деление в 2 перпендикулярных плоскостях |
| **Сарцины** | пакеты 8–16 | деление в 3 плоскостях (микрофлора воздуха) |
| **Стафилококки** | гроздь винограда | деление в разных плоскостях (гнойно-воспалительные) |

### Палочковидные (1–10 мкм × 0,5–2 мкм)
- Правильные (кишечная палочка), неправильные (коринебактерии), ветвящиеся (актиномицеты).
- Концы: обрубленные (сибиреязвенный), закруглённые (кишечная палочка), заострённые (фузобактерии), утолщённые (дифтерия).
- **Не образующие споры** — бактерии (монобактерии, диплобактерии, стрептобактерии).
- **Спорообразующие**:
  - **Бациллы** — спора не превышает диаметр клетки (сибирская язва);
  - **Клостридии** — спора шире клетки (веретено): газовая гангрена, ботулизм, столбняк.

### Извитые и S-образные
- **Вибрионы** — изогнуты <1 оборота (форма запятой): холерный вибрион.
- **Спириллы** — спираль с завитками, **неподвижны** (возбудитель содоку).
- **Спирохеты** — **подвижны**, с осевыми фибриллами: Treponema (сифилис), Borrelia (боррелиоз), Leptospira (лептоспироз).
- S-образные: Campylobacter, Helicobacter.

### Внутриклеточные паразиты (своеобразие)
- **Риккетсии** — облигатные внутриклеточные паразиты (сыпной тиф, лихорадка Скалистых гор), грамотрицательные.
- **Хламидии** — облигатные внутриклеточные, две формы: **элементарные тельца (ЭТ)** (покоящаяся, внеклеточная, нечувствительная к антибиотикам) ↔ **ретикулярные тельца (РТ)** (вегетативная, делится, чувствительна).
- **Микоплазмы** — без клеточной стенки, мембрана со стеролами, класс Mollicutes; пневмония, урогенитальные.
- **Актиномицеты** — ветвящиеся грамположительные, субстратный/воздушный мицелий (актиномикоз); продуценты антибиотиков.

## Структура бактериальной клетки
### Основные (постоянные) структуры
Клеточная стенка, цитоплазматическая мембрана, цитоплазма с включениями, нуклеоид.
### Дополнительные
Капсула, жгутики, пили, плазмиды; споры (эндоспоры) — при неблагоприятных условиях.

### Клеточная стенка (функции)
- придаёт форму; защищает; участвует в делении и транспорте; антигенность; тинкториальные свойства; рецепторы для фагов/антибиотиков.

**Грам +/- (по окраске, метод Г. Грама):**
| | Грам+ (фирмикуты) | Грам- (грациликуты) |
|---|---|---|
| Толщина | 20–80 нм | 14–18 нм |
| Пептидогликан | многослойный, толстый | однослойный (муреиновый мешок) |
| Содержание муреина | 50–90% | 1–12% |
| Тейхоевые кислоты | есть | нет |
| Внешняя мембрана / ЛПС | нет | есть (липополисахарид) |
| Окраска по Граму | сине-фиолетовая | красная |
- **Грам+**: кокки (кроме гонококков/менингококков), бациллы, клостридии, микобактерии, коринебактерии, листерии.
- **Грам-**: гонококки, менингококки, неспорообразующие палочки, извитые.
- **Пептидогликан (муреин)** = гликан (N-ацетилглюкозамин + N-ацетилмурамовая) по гликозидной связи + поперечные тетрапептиды.
- **ЛПС грам-**: липид А (токсичность), ядро, O-цепь (O-антиген).
- Грам- структурные: внешняя мембрана (порины, трансмембранные белки), периплазматическое пространство (ферменты).

**Формы без клеточной стенки:**
- **Протопласты** — полностью без стенки (грам+), изотоническая среда.
- **Сферопласты** — частично (грам-, теряют внешнюю мембрану).
- **L-формы** — утратившие синтез пептидогликана (шаровидные); стабильные/нестабильные (реверсия).

### Цитоплазматическая мембрана
- Бислой фосфолипидов + белки (пермеазы — транспорт). Участвует в осморегуляции, энергетическом метаболизме, делении.
- **Мезосомы** — впячивания мембраны (септальные, латеральные); генерация энергии.

### Цитоплазма и включения
- Цитозоль + рибосомы + включения (гранулы полисахаридов: крахмал/гликоген/гранулеза; полифосфаты — **волютин** (у коринебактерий, по Нейссеру); жировые).
- **Рибосомы** — 70S (30S + 50S), 60% РНК + 40% белок; 16S рРНК в малой, 23S — в большой (16S рРНК — для родства, геносистематика).

### Нуклеоид
- Генетический аппарат = двунитевая ДНК, замкнутая в кольцо; нет ядерной оболочки/ядрышка/гистонов; окраска по Фельгену, Романовскому-Гимзе.
- **Плазмиды** — внехромосомные кольцевые ДНК: R-плазмиды (антибиотикорезистентность), Col-плазмиды (бактериоцины), Tox-плазмиды (токсины), криптические.

### Капсула
- Надоболочечная структура; макрокапсула (>0,2 мкм, видна в световой микроскоп) и микрокапсула (<0,2 мкм, только ЭМ).
- Состав: полисахариды (экзополисахариды), гликопротеины, полипептиды (у сибирской язвы — D-глутаминовая кислота).
- Препятствует фагоцитозу, способствует адгезии, предохраняет от высыхания.
- Окраска: **Бурри-Гинс** (тушь). Утрата капсулы снижает патогенность.

### Жгутики
- Орган движения; 12–20 нм в толщину; состоит: базальное тельце (мотор, диски), крюк, филамент (флагеллин, H-антиген).
- Типы: **монотрихи** (1 жгутик, холерный вибрион), **лофотрихи** (пучок на одном конце), **амфитрихи** (жгутики с обоих концов), **перитрихи** (вся поверхность, кишечная палочка).
- Окраска: по Морозову (серебрение), по Грею.

### Пили (фимбрии)
- Белок пилин; общие (адгезины) и конъюгативные (половые, F-пили, F-плазмида).

### Эндоспора
- Покоящаяся форма грам+ бактерий (Bacillus, Clostridium); **не способ размножения**, а сохранение наследственной информации.
- Образование 18–20 ч; расположение: терминальное (столбняк), субтерминальное (ботулизм), центральное (сибирская язва).
- Оболочка: экзоспориум, оболочка споры, кортекс, стенка сердцевины; включение дипиколиновой кислоты + Са.
- Кислотоустойчивы; окраска по Ожешко/Цилю-Нельсену (споры — красные).
- Прорастание 4–5 ч: активация → инициация → вырастание (одна спора → одна вегетативная клетка).

## Суть главы
Морфология: кокки/палочки/извитые + внутриклеточные паразиты. Клетка: грамположительная (толстый муреин, тейхоевые) vs грамотрицательная (тонкий муреин + внешняя мембрана с ЛПС). Дополнительные структуры — жгутики, капсула, пили, плазмиды; покой — эндоспора. Ключ: **Грам = толщина пептидогликана и наличие внешней мембраны**.
