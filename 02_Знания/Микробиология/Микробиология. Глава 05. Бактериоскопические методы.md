# Микробиология. Бактериоскопические методы исследования

## Методы микробиологической диагностики (обзор)
1. **Микроскопический (бактериоскопический)** — обнаружение микроба в препарате.
2. **Бактериологический** — выделение чистой культуры + идентификация.
3. **Биологический** — заражение животных.
4. **Серологический** — антитела/антигены.
5. **Аллергологический** — реакция организма (аллергены).
6. **Молекулярно-генетические** — фрагменты ДНК/РНК.
- Микроскопический метод — **первый этап** диагностики (ориентировочный).

## Виды микроскопии
Световая (светлопольная, иммерсионная, фазово-контрастная, темнопольная, люминесцентная) + электронная.

### Световая микроскопия
- **Светлопольная** — окрашенные препараты; свет проходит сквозь объект.
- **Иммерсионная** — между объективом и препаратом **масло** (иммерсионная среда: кедровое/минеральное/синтетическое) — повышает чёткость; объектив ×90; масляная (чёрная метка), водная (белая).
- **Фазово-контрастная** — для **неокрашенных живых** малоконтрастных объектов; разница фаз → контраст (аноптральная — разновидность).
- **Темнопольная** — тёмное поле, виден контур, эффект Тиндаля; для живых (спирохет). Препарат "раздавленная"/"висячая" капля.
- **Люминесцентная (флюоресцентная)** — свечение объекта после облучения (УФ); иммунолюминесцентная — экспресс-выявление антигенов.

### Электронная микроскопия
- Вместо света — **поток электронов** (электронная пушка), вместо линз — **электромагниты**; разрешение <1 Å.
- **Просвечивающая (ПЭМ/ТЕМ)** — пучок через ультратонкий срез.
- **Сканирующая (РЭМ/SEM)** — пучок сканирует поверхность → трёхмерное изображение.
- Методы подготовки: напыление (палладий), реплики, негативное контрастирование (уранилацетат).

## Окрашивание препаратов
- **Фиксация** перед окраской — закрепление + инактивация (физ. способ — нагрев; хим. — спирт/эфир, смесь Никифорова).
- **Простые методы** — один краситель (метиленовый синий, фуксин, генциановый фиолетовый).
- **Сложные (дифференциальные)** — несколько красителей:

### Окраска по Граму (главный тинкториальный метод, 1884)
1. Генциановый фиолетовый → 2. раствор Люголя (йод) → 3. обесцвечивание спиртом → 4. фуксин.
- **Грам+** — сине-фиолетовые; **Грам−** — красные.
- Зависит от **строения клеточной стенки** (см. глава 4).

### Окраска по Цилю-Нельсену (для кислотоустойчивых — микобактерии туберкулёза, 1883)
- Кислотоустойчивые → красные палочки; остальные → синие.

### Другие
- По **Бурри-Гинсу** — капсулы (тушь: бактерии красные, вокруг капсула).
- **Ожешко / Циль-Нельсен** — споры (споры красные, клетки синие).
- **Нейссер** — волютин; **Златогоров, Пешков** — споры; **Леффлер** (серебрение) — жгутики.

## Суть главы
Диагностика начинается с микроскопии. Ключевые инструменты: световая микроскопия (иммерсия, фазовый контраст, тёмное поле, люминесценция) и электронная. Главный краситель — **по Граму**; для кислотоустойчивых — **Циль-Нельсен**.
