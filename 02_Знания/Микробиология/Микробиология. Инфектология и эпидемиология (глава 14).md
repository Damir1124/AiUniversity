# Микробиология. Основы инфектологии и эпидемиологии

## Инфекция (определения)
- **Инфекция** — совокупность взаимодействий патогенного микроба с макроорганизмом (проявление паразитизма).
- **Инфекционный процесс** — результат внедрения и размножения возбудителя в макроорганизме.
- **Инфекционная болезнь** — крайнее проявление инфекционного процесса.

## Стадии инфекционного процесса
1. **Внедрение** патогена + адаптация (входные ворота).
2. **Колонизация** входных ворот.
3. **Генерализация** (распространение по организму).
4. Накопление продуктов метаболизма, ферментов, токсинов.
5. **Окончание/исход** (элиминация + иммунитет, либо летальный).

## Признаки инфекционной болезни
Строго определённый возбудитель; **заразительность**; **инкубационный (скрытый) период**; формирование **иммунитета**.

## Периоды инфекционной болезни
**Инкубационный** (скрытый; 1–3 нед для большинства; короче при высокой вирулентности) → **продромальный** (2–4 дня, неспецифические признаки, токсикация) → **разгар/период выраженных симптомов** → **выздоровление**.

## Классификация инфекций
- **По происхождению**: эндогенные (своя микрофлора) / экзогенные (извне).
- **По числу возбудителей**: моноинфекция / смешанная (микст).
- **По этиологии**: бактериальные, вирусные, грибковые, протозойные.
- **По клинике/течению**: острые, хронические; местные (очаговые) / генерализованные.
- Особые: **носительство** (бессимптомное), **латентная** (скрытая, реактивируется), **вторичная** (2-й возбудитель), **реинфекция** (после выздоровления), **суперинфекция** (на фоне текущего).

## Эпидемический процесс
- Уровни: спорадическая заболеваемость → **эпидемия** → **пандемия**.
- **Элементы (звенья)**: источник инфекции → механизмы/пути/факторы передачи → **восприимчивый организм**.
- **Источник инфекции** — организм (больной/носитель). **Резервуар** — объекты внешней среды (почва, вода).
- Классификация по источнику:
  - **Антропонозные** — источник человек (человек не болеет от животных).
  - **Зоонозные** — источник животные.
  - **Зооантропонозные** — человек и животные.
  - **Сапронозные** — резервуар — внешняя среда (источника нет).

## Механизмы передачи
- **Фекально-оральный** (кишечные инфекции).
- **Аэрогенный** (воздушно-капельный / воздушно-пылевой).
- **Трансмиссивный** (кровяные — через кровососущих: сыпной тиф, малярия, чума).
- **Парентеральный** (кровь), **вертикальный** (от матери к плоду), **контактный**.
- Группы: кишечные, дыхательных путей, кровяные, наружных покровов (венерические).

## Патогенность и вирулентность
- **Патогенность** — потенциальная способность вызывать болезнь (видовая, генетич. детерминирована, плазмидами патогенности).
- **Вирулентность** — степень патогенности, **индивидуальна для штамма**; измеряется (Dlm).
- Микробы: патогенные (облигатно-патогенные) / условно-патогенные / непатогенные (сапрофиты).

### Факторы патогенности
- **Структурные** (прикрепление к клетке): **адгезины** (пили, фимбрии, жгутики), капсула.
- **Секретируемые**: ферменты агрессии/патогенности (коллагеназа, гиалуронидаза, лецитиназа, ДНКаза), **токсины**, бактериоцины.
- **Антифагоцитарные** — капсула (препятствует фагоцитозу), **корд-фактор** микобактерий (незавершённый фагоцитоз).
- **Инвазины** — проникновение в клетки.

### Токсины
| Признак | Экзотоксин | Эндотоксин |
|---|---|---|
| Происхождение | выделяется живой клеткой | связан с клеткой (лизис) |
| Химическая природа | **полипептид** (белок) | **липополисахарид** |
| Термостабильность | **термолабилен** (гибнет 60°C) | термостабилен |
| Лихорадка | не вызывает | **пирогенность** (вызывает) |
| Специфичность | высокая | низкая |
| Иммуногенность | высокая (→ антитоксин) | слабая |
| Анатоксин | переходит (3–4 недели) | не образует |
| Источник | Грам+ и Грам− | Грам− (ЛПС) |
- **Экзотоксины по механизму**: цитотоксины (блок. синтез белка — дифтерийный), мембранотоксины (проницаемость — холероген), токсины взаимодействия клеток (стафилококк).

## Врождённая защита (роль макроорганизма)
- Лизоцим, комплемент, интерферон, фагоциты (нейтрофилы, макрофаги), natural antibodies, ПАМП/ПРАМП-рецепторы.
- **Комплемент** (П. Эрлих): активирует фагоцитоз, лизис; 3 пути активации (классический — через антиген-антитело: C1→C4→C2→C3; и др.).
- Фагоцитоз (завершённый/незавершённый — микобактерии).

## Суть главы
Инфекция = взаимодействие патогена и хозяина (5 стадий → болезнь). Эпидпроцесс = источник → пути передачи → восприимчивый. Вирулентность (штамм) — мера патогенности. Ключ: **экзотоксин — белок, термолабилен, переходит в анатоксин; эндотоксин — ЛПС, пирогенный**.
