# Микробиология. Бактериологическое исследование

## Цель
Выделение **чистой культуры возбудителя** + **идентификация** (морфологические, тинкториальные, культуральные, биохимические свойства); при необходимости — фаготипирование, серотипирование, определение чувствительности к антибиотикам.

## 4 этапа бактериологического метода
1. **I** — посев материала на питательные среды для получения **изолированных колоний**.
2. **II** — из отдельных колоний → накопление чистой культуры.
3. **III** — проверка чистоты + изучение биохимических (сахаролитических/протеолитических) свойств → **идентификация** (определение вида).
4. **IV** — учет результатов, выдача заключения.

## Отбор и транспортировка материала
- Материал: кровь, моча, гной, мокрота, фекалии, желчь, смывы (правила асептики).
- Вакуумные пробирки (кровь), стерильные контейнеры (моча/кал), транспортные системы со средой (тампоны), двухфазные флаконы (гемокультура).
- Отбор **до** антибиотикотерапии; исключить антибиотики/антисептики.
- Транспортировка быстро, при 4°C; анаэробы — в бескислородной среде.
- Остатки материала уничтожают автоклавированием.

## Чистая культура и колония
- **Чистая культура** — популяция одного вида из изолированной колонии.
- **Колония** — видимое скопление (потомство, как правило, одной клетки).
- Цель — **изолированные колонии**.

## Методы разобщения клеток (изолирование колоний)
- **Метод Пастера** — разведения в жидкой среде (исторический).
- **Метод Коха** — разведения в расплавленном агаре.
- **Метод Дригальского** — тампоном/шпателем последовательно по чашкам.
- **Посев штрихом** (бак. петлёй) — самый распространённый для аэробов.
- Обогащение: биологический (заражение животных), химический (кислота для микобактерий), физический (прогревание для споровых).

## Идентификация
- **Морфологические**, **тинкториальные** (Грам) — микроскопия мазков.
- **Культуральные** — рост на плотной/жидкой среде (форма, размер, прозрачность, цвет, поверхность, рельеф колоний).
- **Биохимические**: сахаролитические (среды Гисса — кислота/газ в поплавке), протеолитические (разжижение желатина, свёрнутая сыворотка, молочный агар: индол, аммиак, H₂S), **ОФ-тест** (окисление-ферментация, глюкоза + бромтимоловый синий + вазелиновое масло).
- Автоматические анализаторы (Vitek II).

## Выделение чистой культуры анаэробов
Создание анаэробных условий:
- Среда **Китта-Тароцци** под вазелиновым маслом (среда накопления).
- Высокий столбик агара; эксикаторы/анаэростаты/**GasPak** (капнофильная, микроаэрофильная CampyPak, анаэробная H₂/CO₂).
- Метод **Фортнера** (аэробы + анаэробы на одной чашке, парафин), метод Цейсслера, Вейнберга, Вейона-Виньяля, Перетца, "перевёрнутых чашек".

## Суть главы
Бакметод-4 этапа от посева до идентификации вида. Ключевое: получить изолированные колонии → чистую культуру → идентифицировать по биохимическим (сахаролитическим/протеолитическим) признакам. Анаэробы требуют сред с откачкой кислорода.
