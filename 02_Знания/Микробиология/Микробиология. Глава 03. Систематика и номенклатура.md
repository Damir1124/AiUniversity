# Микробиология. Систематика и номенклатура микробов

## Определения
- **Систематика** — устанавливает место микробов в природе, их эволюционное родство; объединяет **номенклатуру, классификацию, идентификацию**.
- **Номенклатура** — правила/принципы названия микробов, список названий.
- **Классификация** — распределение микробов на таксоны (группы) по общим признакам.
- **Таксономия** — раздел систематики о принципах, правилах, методах классификации.
- **Идентификация** — установление принадлежности микроба к таксономической категории по свойствам (морфологические, тинкториальные, биохимические, молекулярные, антигенные).

## Признаки для описания новых бактерий
1. **Морфологические** — форма/размер, наличие жгутиков, капсулы, спорообразование, подвижность.
2. **Тинкториальные** — отношение к красителям (в первую очередь окраска по Грамму).
3. **Культуральные** — характер роста на плотных/жидких средах.
4. **Биохимические** — потребности в питании, ферментация углеводов, распад белков, энергетика, отношение к температуре/рН/кислороду, химсостав.
5. **Антигенные** и **генетические** (состав ДНК, рибосомальная РНК).
6. **Экологические** — место обитания, круг хозяев.
- **Фенотипические** показатели = внешние признаки; **генотипические** = наследственные (соотношение пуринов/пиримидинов, плазмиды, рестрикционные фрагменты НК).

## Таксономические категории (иерархия, от крупной к мелкой)
`Домен → Царство → Отдел → Класс → Порядок (отряд) → Семейство → Род → Вид`
- Обязательные: домен, царство, отдел, класс, порядок, семейство, род, вид.
- Необязательные: подкласс, подотдел, подсемейство, подрод, подвид.
- **Основная единица — ВИД**: группа близких микробов общего происхождения, сходных по морфологии/биохимии/физиологии, приспособленных к среде. Каждый вид имеет **типовой штамм** (эталон).
- **Род** — группа близкородственных видов (типовой вид: Escherichia — типовой вид E. coli).
- **Триба** — группа близкородственных родов.

## Варианты (типы) внутри вида
- **Серовар** — по антигенным свойствам.
- **Фаговар** — по чувствительности к бактериофагам.
- **Хемовар** — по биохимии.
- **Биовар** — по биологическим/культуральным признакам.
- **Патовар** — по патогенности.
- **Морфовар**, **культивар**, **геновар**, **риботип**.

## Номенклатура (бинарная двойная, по К. Линнею)
- Названия **латиницей**. Род → выше: одним словом; **вид — биноминальный (род + вид)**.
- Первое слово — **род** (заглавная), второе — **вид** (строчная); оба курсивом: *Escherichia coli*, при повторе — *E. coli*.
- Если только род: слово `sp.` (species).
- **Род** обозначают по форме клеток/фамилии учёного; **вид** — по признаку колоний или среде обитания.
- Триноминально называют подвиды (`Klebsiella pneumoniae subsp. ozenae`).
- Окончания таксонов выше рода: порядок **-ales**, подпорядок **-ineae**, семейство **-aceae**, подсемейство **-oideae**.
- Штаммы обозначают с аббревиатурой коллекции: `Clostridium butyricum ATCC 13398`, `B. subtilis ВКПМ 3815`.

## Культуры: чистая / смешанная / клон / штамм / популяция
- **Культура** — микробы, выращенные на среде.
- **Чистая культура** — особи **одного вида**.
- **Смешанная культура** — несколько видов вместе.
- **Клон** — потомство **одной** материнской клетки.
- **Штамм** — чистая культура вида, выделенная из конкретного объекта, с незначительными отличиями от эталона.
- **Популяция** — совокупность бактерий вида от 1–нескольких клеток.

## Систематика вирусов, грибов, простейших
- **Вирусы** — царство Vira; основа классификации — **тип НК** (РНК-/ДНК-содержащие); таксоны: вид→род→подсемейство→семейство.
- **Грибы** — царство Fungi (Mycota), отделы Myxomycota и Eumycota; высшие/низшие; классы (вкл. возбудителей микозов) — аскомицеты, базидиомицеты, дейтеромицеты (несовершенные).
- **Простейшие** — царство Animalia, подцарство Protozoa; патогенные в 3 типах: Sarcomastigophora, Apicomplexa (споровики), Ciliophora.

## Суть главы
Систематика организует разнообразие микробов: назначает имена (бинарная номенклатура), раскладывает по таксонам (вид = основа), идентифицирует по свойствам. Ключевое для запоминания: **вид → типовой штамм; род + вид = двойное латинское название**.
