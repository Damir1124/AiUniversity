# Микробиология. Строение и репродукция вирусов

## Определение
**Вирусы** — мельчайшие формы жизни **без клеточного строения**, образуют царство **Vira**. **Вирион** = зрелая внеклеточная вирусная частица.

## Уникальные свойства вирусов
1. **Ультрамикроскопические размеры** (нм): мелкие 10–25 нм (полиомиелит), средние 100–120 нм (грипп), крупные ~350 нм (оспа).
2. **Один тип нуклеиновой кислоты** (ДНК или РНК) — деление на ДНК- и РНК-содержащие вирусы.
3. **Облигатный внутриклеточный паразитизм** — реплицируются только в живых клетках (нет собственных систем синтеза белка/энергии).
4. **Простое строение вириона** (геном + капсид/суперкапсид); нет цитоплазмы, рибосом, мембран.
5. **Дизъюнктивная (разобщённая) репродукция** — НК и белки синтезируются раздельно и собираются в дочерние частицы.

## Формы вирионов
Палочковидная (табачная мозаика), пулевидная (бешенство), сферическая (герпес, ВИЧ), нитевидная (филовирусы), овальная (оспа), сперматозоидная (бактериофаги).

## Структура
- **Геном** (НК) + **капсид** (белковая оболочка из капсомеров) = **нуклеокапсид**.
- **Простые (безоболочечные, "голые")** — НК + капсид.
- **Сложные (оболочечные, "одетые")** — + **суперкапсид** (пеплос) — модифицированная ЦПМ клетки со встроенными вирусными белками.
- **Шипы (пепломеры)** — на суперкапсиде: у гриппа — **гемагглютинин и нейраминидаза**; без шипов вирус теряет инфекционность.
- **Матриксный белок (М)** — между суперкапсидом и нуклеокапсидом.
- Капсомеры: мономерные/полимерные (2130 у табачной мозаики).

## Типы симметрии (определяется нуклеокапсидом!)
- **Спиральный** — палочковидные/пулевидные/нитевидные (табачная мозаика).
- **Кубический** — многогранники (икосаэдр 20 граней, додекаэдр 12) → сферическая форма (герпес, полиомиелит).
- **Комбинированный (смешанный)** — бактериофаги: головка кубическая + хвост спиральный.

## Вирусный геном
| Тип | Пример |
|---|---|
| Однонитевая линейная ДНК | парвовирусы |
| Двунитевая линейная ДНК | герпес |
| Двунитевая кольцевая ДНК | папилломавирус |
| Двунитевая кольцевая ДНК с дефектом цепи | гепатит В |
| +РНК (матричная) | пикорнавирусы (полио) |
| −РНК (+ транскриптаза) | парамиксовирусы, рабдовирусы; фрагментированная — грипп (8) |
| Двуцепочечная РНК | реовирусы (10) |
| Диплоидная +РНК (+ обратная транскриптаза) | ретровирусы (ВИЧ) |
| Одноцепочечная кольцевая РНК | вирус гепатита D (дефектный, нужен вирус-помощник — гепатит В) |
- **+РНК** = выполняет и функцию иРНК; **−РНК** = только наследственная + нужна вирусная транскриптаза.
- Гены: структурные (белки вириона) и регуляторные.

## Жизненный цикл (этапы)
1. **Адсорбция** — прикрепительные белки (антирецепторы) ↔ клеточные рецепторы (муко-/липопротеиновые); 5–90 мин.
2. **Проникновение** — слияние суперкапсида с мембраной (оболочечные) или рецептор-опосредованный эндоцитоз через эндосомы (безоболочечные).
3. **Депротеинизация** — освобождение вирусной НК.
4. **Синтез** вирусных НК и белков.
5. **Сборка** дочерних вирионов.
6. **Выход** из клетки (почкование / лизис).
- "Теневая фаза" (эклипс) — этап, когда вирус в клетке не обнаруживается.

## Культивирование вирусов
- В **организме животных** (лабораторные животные);
- в **куриных эмбрионах (РКЭ)** — признаки: гибель, поражения;
- в **тканевых/клеточных культурах** — цитопатическое действие (**ЦПД**), бляшки, гемадсорбция, изменение цвета индикатора.
- Репродукция основных клеточных/ядерных вирусов.

## Суть главы
Вирус = геном (ДНК/РНК) в белковой оболочке (капсид), у сложных — + суперкапсид с шипами. Только внутриклеточный паразит с дизъюнктивной репродукцией. Ключевое: **+РНК сам = иРНК; −РНК требует транскриптазу**.
