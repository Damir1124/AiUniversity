# Микробиология. Генетика бактерий

## Наследственный аппарат
- Геном = **нуклеоид** (бактериальная хромосома) + **плазмиды**.
- Хромосома E. coli: ~5 млн н.п., до 4000 генов.
- **Плазмиды** — небольшие автономные внехромосомные двухцепочечные кольцевые ДНК (0,1–5% нуклеоида), самостоятельная репликация. Копийность: мелкие 10–30 копий, крупные 1–2 копии.
- **Мобильные элементы генома**: IS-последовательности (инсерционные), **транспозоны**, интегроны, островки патогенности.

## Плазмиды (виды)
| Плазмида | Функция |
|---|---|
| **F** (фертильности) | половые факторы, конъюгация (донорство) |
| **R** (резистентности) | множественная лекарственная устойчивость к антибиотикам |
| **Tox** (патогенности) | токсины: Ent (энтеротоксин), Hly (гемолизин) |
| **Col** | бактериоцины (колицины) |
| **D** | биодеградация |
| **Криптические** | без выявляемого фенотипа |
- Плазмиды автономные / интегрированные; трансмиссивные / нетрансмиссивные.

## Мобильные элементы
- **IS-элементы** — вставочные последовательности (~средние размеры), перемещаются по хромосоме, вызывают мутации, обеспечивают рекомбинацию.
- **Транспозоны** — крупнее IS (2000–25000 н.п.), содержат фрагмент ДНК с генами + 2 концевых **инвертированных повтора**; при встраивании/исключении вызывают делеции, дупликации, инверсии; не автономны.
- **Интегроны**, **островки патогенности** (хромосома Salmonella, плазмиды Shigella, фаги V. cholerae).

## Изменчивость бактерий
### Ненаследственная (модификационная)
- Изменение признаков под влиянием факторов среды, **не наследуется**.

### Наследственная (мутации + рекомбинации)
**Мутации** (изменение последовательности ДНК):
- **Спонтанные** (1·10⁻⁵–1·10⁻¹⁰) / **индуцированные** (10⁻⁷–10⁻⁴, мутагены: физические — УФ/ионизация, химические).
- **Точечные / генные / хромосомные**; прямые / обратные; летальные / сублетальные / нейтральные.
- Типы: нонсенс (бессмысленный кодон), делеции, инсерции, инверсии, транслокации.
- **Репарация** (восстановление ДНК).

### Рекомбинация (перенос генов) — 3 механизма:
1. **Трансформация** — поглощение свободной ДНК (Гриффит, Освальд Эвери — ДНК = вещество наследственности); in vivo/in vitro; хромосомная/плазмидная ДНК.
2. **Конъюгация** — перенос через конъюгационный мостик при контакте (**F-плазмида**, донор F⁺; при Hfr-плазмиде передаётся и фрагмент хромосомы).
3. **Трансдукция** — перенос гена умеренным фагом (см. гл. 7):
   - **неспецифическая** (случайный фрагмент);
   - **специфическая** (строго определённые гены);
   - **абортивная** (ДНК не включается в геном реципиента, признак не проявляется).

## Генная инженерия
- Перенос нужного гена в другой организм/встраивание искусственно синтезированного гена; **векторы** — плазмиды (R-плазмиды), фаги, вирусы.
- Используется для получения рекомбинантных белков, биотехнологической продукции.

## Суть главы
Наследственность бактерий = нуклеоид + плазмиды (+ мобильные элементы). Изменчивость: модификационная (не наследуется) и мутационная/рекомбинационная. Перенос генов: **трансформация, конъюгация, трансдукция**. R-плазмиды и транспозоны — ключ к антибиотикорезистентности.
