# Предел функции

## Определения

**Предел** функции $f(x)$ при $x\to a$ равен $L$, если для любого $\varepsilon>0$ существует $\delta>0$, такое что из $0<|x-a|<\delta$ следует $|f(x)-L|<\varepsilon$.

## Факты

- Предел — база для [[Производная функции]] и интеграла.
- Единственность предела.

## Формулы

- $\lim_{x\to a} (f+g) = \lim f + \lim g$
- $\lim_{x\to a} (fg) = \lim f \cdot \lim g$
