# Производная функции

## Определения

**Производная** функции $f$ в точке $x$ — предел отношения приращения функции к приращению аргумента:

$$f'(x) = \lim_{h\to0} \frac{f(x+h)-f(x)}{h}$$

## Факты

- Производная характеризует мгновенную скорость изменения функции.
- Существование производной в точке подразумевает [[Непрерывность]] функции в этой точке.
- Обратное неверно: непрерывная функция может не иметь производной (например, $|x|$ в нуле).

## Формулы

1. $(x^n)' = n x^{n-1}$
2. $(\sin x)' = \cos x$
3. $(e^x)' = e^x$
4. Правило Лейбница: $(fg)' = f'g + fg'$

## Алгоритмы / Логические цепочки

1. Вычислить $\frac{f(x+h)-f(x)}$.
2. Упростить.
3. Разделить на $h$.
4. Перейти к пределу $h\to0$.
