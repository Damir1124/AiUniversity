# Микробиология. Шпаргалка для запоминания

## Прокариоты vs эукариоты
| Признак | Прокариоты | Эукариоты |
|---|---|---|
| Ядро | нуклеоид (нет мембраны) | есть |
| Рибосомы | 70S | 80S |
| Митохондрии/ЭПС/Гольджи/лизосомы | нет | есть |
| Пептидогликан в стенке | есть | нет |
| Стерины (мембрана) | нет | есть |

## Грам + / Грам − (метод Грама)
| | Грам+ | Грам− |
|---|---|---|
| Стенка | толстая 20-80 нм | тонкая 14-18 нм |
| Муреин | 50-90% | 1-12% |
| Тейхоевые кислоты | есть | нет |
| Внешняя мембрана/ЛПС | нет | есть |
| Цвет | сине-фиолетовый | красный |

## Морфология
- Кокки: микро/дипло/стрепто/тетра/сарцина/стафило.
- Палочки: бациллы (спора ≤ клетки) / клостридии (спора > клетки).
- Извитые: вибрионы, спириллы (неподвижны), спирохеты (подвижны).
- Внутриклеточные: риккетсии, хламидии (ЭТ→РТ), микоплазмы (без стенки), актиномицеты.
- Структуры: капсула, жгутики (моно/лофо/амфи/перитрихи), пили, плазмиды, эндоспора.

## Вирусы
- Вирион = геном + капсид (+ суперкапсид у сложных).
- Симметрия: спиральная / кубическая (икосаэдр) / смешанная (фаги).
- **+РНК** = иРНК сама; **−РНК** = нужна транскриптаза.
- Жизненный цикл: адсорбция → проникновение → депротеинизация → синтез → сборка → выход.
- Дизъюнктивная репродукция.
- Культивирование: животные, куриные эмбрионы, культуры клеток (ЦПД).

## Бактериофаги
- **Вирулентный** — лизирует клетку (литический цикл).
- **Умеренный** — интегрируется (профаг, лизогения); индукция → лизис.
- Трансдукция (неспециф./специф./абортивная).
- Фаговая конверсия; применение: фаготипирование, фаготерапия.

## Физиология
- Экзоферменты (наружу) / эндоферменты.
- Энергия: дыхание (окислит.) / брожение (спиртовое, молочнокислое, муравьинокислое, маслянокислое).
- Сахаролитическая и протеолитическая активность — идентификация.

## Генетика
- Геном = нуклеоид + плазмиды (+ транспозоны, IS).
- Плазмиды: **F** (фертильность), **R** (резистентность), **Tox** (токсины), **Col** (колицины), **D** (деградация).
- Перенос: **трансформация**, **конъюгация** (F-плазмида), **трансдукция** (фаги).
- Изменчивость: модификационная (не наследуется) / мутационная.

## Уничтожение микробов
`Асептика < Антисептика < Дезинфекция < Стерилизация`
- Асептика — предотвращение попадания; антисептика — в ране; дезинфекция — частичная; **стерилизация** — полная (вкл. споры).
- Стерилизация: автоклавирование (120°C/1,1 атм/45 мин; 132°C/2 атм/20 мин), сухое жало (200°C), тиндализация (дробная), лучевая, газами.

## Токсины
| | Экзотоксин | Эндотоксин |
|---|---|---|
| Природа | белок | ЛПС |
| Термо | лабилен | стабилен |
| Лихорадка | нет | да (пирогенен) |
| Анатоксин | да | нет |
| Источник | Грам+/− | Грам− |

## Антибиотики
- Действие: бактерицидное / бактериостатическое; спектр.
- Получение: биосинтез / полусинтетич. / синтетич.
- Чувствительность: МИК, МБК, диско-диффузионный метод.
- Резистентность: R-плазмиды, β-лактамаза, изменение мишени.

## Инфекция
- Периоды: инкубационный → продромальный → разгар → выздоровление.
- Эпидпроцесс: источник → механизм/пути передачи → восприимчивый.
- Происхождение: антропонозы (человек) / зоонозы (животные) / зооантропонозы / сапронозы (среда).
- Патогенность (вид) / вирулентность (штамм); факторы патогенности (адгезины, капсула, ферменты, токсины).

## Противопоставления (ядро)
- **Бактериостатическое ↔ бактерицидное**.
- **Вирулентный фаг ↔ умеренный**.
- **Экзотоксин ↔ эндотоксин**.
- **Стерилизация ↔ дезинфекция** (полная ↔ частичная).
- **+РНК ↔ −РНК** (сам = иРНК ↔ нужна транскриптаза).
