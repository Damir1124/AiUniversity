# Шпаргалка. Дифференцирование

## Производные элементарных функций

| f(x) | f'(x) |
|---|---|
| $c$ | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\frac{1}{x}$ |

## Правила

| Правило | Формула |
|---|---|
| Сумма | $(f+g)'=f'+g'$ |
| Произведение | $(fg)'=f'g+fg'$ |
| Частное | $\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^2}$ |
| Сложная функция | $(f(g(x)))'=f'(g(x))\cdot g'(x)$ |
