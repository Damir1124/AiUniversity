# Эндокринная система. Шпаргалка для запоминания

## Где что вырабатывается

| Железа | Клетки | Гормоны |
|---|---|---|
| **Гипоталамус** | крупноклеточные ядра | вазопрессин (АДГ), окситоцин |
| — // — | мелкоклеточные ядра | либерины, статины |
| **Аденогипофиз** | соматотропоциты | СТГ (рост) |
| | тиреотропоциты | ТТГ → щитовидка |
| | кортикотропоциты | АКТГ → кора надпочечников |
| | гонадотропоциты | ФСГ, ЛГ |
| | лактотропоциты | пролактин |
| **Эпифиз** | пинеалоциты | мелатонин |
| **Щитовидная** | тироциты | тироксин Т4, трийодтиронин Т3 |
| — // — | C-клетки (парафолликулярные) | кальцитонин (↓Ca) |
| **Околощитовидные** | главные паратироциты | паратгормон (↑Ca) |
| **Надпочечник · кора** — клубочковая | кортикостероциты | минералокортикоиды (альдостерон) |
| — пучковая | — // — | глюкокортикоиды (кортизол) |
| — сетчатая | — // — | андрогены |
| **Надпочечник · мозговое** | светлые хромаффиноциты | адреналин |
| | тёмные хромаффиноциты | норадреналин |
| **APUD-система** | одиночные эндокриноциты | биогенные амины + пептиды |

## Противопоставления для заучивания

- **Кальцитонин** (щитовидная, C-клетки) **↓Ca** ←→ **Паратгормон** (околощитовидные) **↑Ca**.
- **Т3** в **3–10 раз** активнее **Т4**.
- **Кора надпочечников** — целомическое происхождение, стероидные гормоны; **мозговое вещество** — нейральное, катехоламины.
- Мелатонин → эпифиз; серотонин/гастрин/глюкагон/соматостатин → APUD-клетки (желудочно-кишечные).

## Запоминалочки (мнемоника зон коры)
"**Клубочковая — соль (минерало)**, **пучковая — сахар (глюко)**, **сетчатая — секс (андро)**."

## Логические цепочки
- Гипоталамус (либерины/статины) → портальная система → **аденогипофиз** (тропные гормоны) → периферические железы.
- Гипоталамус (АДГ, окситоцин) → аксоны → **нейрогипофиз** (тельца Херринга) → кровь.
- Стресс → симпатика + хромаффиноциты → адреналин/норадреналин в кровь → учащение ритма, глюкоза.
