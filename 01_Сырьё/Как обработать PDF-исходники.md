# Как обработать PDF-исходники

В папке `raw/` лежит крупный PDF (`Афнфсьев.2012.PDF`, ~120 МБ, судя по всему сканированный). Система фильтрации (`_scripts/process.ps1` и промпты-профили) работает с **Markdown (.md)**. PDF — это картинки текста, поэтому перед фильтрацией его нужно превратить в текст.

---

## Вариант A. Текст уже встроен в PDF (не сканы)

Выполните извлечение текста любым инструментом и сохраните как .md:

**Python + pdfminer:**
```python
# pip install pdfminer.six
from pdfminer.high_level import extract_text
text = extract_text("raw/Афнфсьев.2012.PDF")
open("raw/Афнфсьев.md", "w", encoding="utf-8").write(text)
```

**или** в Obsidian нельзя, но есть онлайн-сервисы / командные утилиты `pdftotext`.

---

## Вариант B. PDF — скан (нужна OCR)

1. Прогоните PDF через OCR к сканированию (например, **Tesseract** с русским языком, Adobe, или онлайн).
2. Получите текстовый `.md`/`.txt`, положите в `raw/`.
3. Теперь можно обрабатывать через режимы.

---

## Дальше (после получения .md)

```powershell
# сухая выжимка
powershell -ExecutionPolicy Bypass -File _scripts\process.ps1 -Mode dry
```

**Но** для НАСТОЯЩЕЙ нейросетевой фильтрации («без воды») передайте текст в dsh
с профилем из `_scripts/prompts/*.prompt.md` — именно модель выжимает факты/формулы,
убирает лирику и заполняет разделы шаблона.

---

## Рекомендация

Если документа большой — не обрабатывайте целиком за раз. Разбейте на **главы/лекции**
по ~10–20 страниц и каждую прогоняйте отдельно. Так лучше контроль качества и выше точность.
