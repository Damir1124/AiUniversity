# Синхронизация на телефон (Android) через Obsidian Git

Плагин **Obsidian Git** уже установлен в Vault (`.obsidian/plugins/obsidian-git/`, версия 2.39.0) и опубликован в репозитории. Нужно только **стянуть репозиторий на телефон** и **включить плагин**.

> ⚠️ На телефоне (Android) Obsidian Git использует **встроенный git** (без отключения Community plugins он недоступен). Сначала включите Community plugins.

---

## Шаг 1. Включить Community plugins (разово)

1. Откройте Obsidian на телефоне.
2. **Настройки** (⚙ шестерёнка) → **Community plugins**.
3. Включите тумблер `Turn on community plugins` (Obsidian попросит подтверждение — соглашайтесь).
4. Выключите `Safe mode`.

## Шаг 2. Клонировать репозиторий как Vault

> На телефоне уже должен быть установлен **Obsidian** (Google Play).

**Вариант A — клон внутри уже открытого Vault (рекомендую если нужно только читать):**
1. Установите **Obsidian Git** из каталога `Community plugins` в поиске: наберите `Git`, найдите плагин **"Git" от Vinzent**, установите, включите.
2. В настройках плагина → **Clone an existing remote repo** (команда `Git: Clone`).
3. Введите remote URL: `https://github.com/Damir1124/AiUniversity.git`.
4. Укажите директорию (создайте пустую).
5. Перезапустите Obsidian.

**Вариант B — открыть папку прямо:**
1. Наберите командой `Git: Clone` remote URL, Obsidian создаст Vault из репозитория.
2. Когда предложит удалить локальный `.obsidian` — **откажитесь удалять** (мы хотим сохранить `.obsidian/plugins/obsidian-git`, который уже в репозитории). Если предложит — скажите `NO`.
3. Откройте получившуюся папку как Vault.

## Шаг 3. Указать токен и имя в настройках плагина

1. Создайте **Personal Access Token (PAT)** на GitHub (Settings → Developer settings → Personal access tokens → generate, scope: `repo`).
2. В Obsidian → Настройки → **Git (Vinzent)**:
   - **Username**: `Damir1124`
   - **Password/Personal access token**: вставьте ваш PAT
   - **Author name/email** для коммитов: `Damir` / ваш email.

> Токен хранится **только в локальном хранилище телефона**, в Git/репозиторий не попадает.

## Шаг 4. Синхронизация

Плагин настроен на **автосинхронизацию** (каждые 5 минут pull/push). Можно также вручную:

- **Pull** — загрузить обновления с GitHub на телефон (панель команд → `Git: Pull`).
- **Commit-and-sync** — закоммитить + pull + push (команда `Git: Commit-and-sync`).

При изменении заметок на телефоне и на компьютере **в один момент** могут быть конфликты — плагин предложит их решить (заметки с конфликтами появятся в папке / отдельной вкладке).

## Что синхронизируется / не синхронизируется

| Синхронизируется | Не синхронизируется |
|---|---|
| Все `.md` заметки, карточки, карта знаний | PDF-исходники (>100 МБ) |
| Плагин Obsidian Git (.obsidian/plugins) | Библиотеки `_scripts/lib/**` |
| Конвертер `_scripts/pdf2md.py`, установщик | Временные файлы `_scripts/_pipsrc`, `__pycache__` |
| Конфиг `_config/*`, промпты, шаблоны | Локальные настройки Obsidian (тема, workspace) |

---

## Частые проблемы

- **"Took too long to clone"** — проверьте интернет, повторите.
- **Пулльный конфликт** — открывайте файл с маркерами `<<<<<<<`, поправьте вручную, сохраните, затем `Git: Commit-and-sync`.
- **Ошибка авторизации** — токен просрочен/не той длины, пересоздайте PAT и обновите в настройках плагина.
